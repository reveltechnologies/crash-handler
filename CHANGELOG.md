# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-10-25

### Added
- Single-page, non-scrollable crash handler web interface (`src/index.html`).
- Custom pixel art banner logo with blocky red typography, black outlines, subtle drop shadow, and a built-in sniper crosshair reticle inside the 'A' (`src/banner.png`).
- Original, legally compliant seamless 16x16 pixel dirt background texture with subtle fine stone pebbles (`src/dirt.png`).
- Interactive crash log submission workflow with direct file picker trigger on submit.
- Dynamic loading animations featuring 3 staggered jumping and 360-degree spinning pixel dirt blocks.
- Real-time diagnostic status updates and animated progressive text states (`Loading...` through parsing stages).
- Community footer with Minecraft compliance disclaimer and legal modal links (Terms of Use, Privacy Policy, Contact).
- Texture and banner generator automation scripts (`generate_banner.py`, `generate_dirt.py`).

### Removed
- Legacy template placeholder files and example changelog entries.
